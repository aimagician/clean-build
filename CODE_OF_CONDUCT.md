# Code of Conduct

clean-builder is a small project, and it should be a good place to ask
questions, report problems and send patches — whoever you are and whatever your
level of experience.

## Expected behavior

- Be respectful and assume good intent. Critique code and ideas, not people.
- Keep discussions on topic and constructive, especially in security
  discussions, where details matter and tempers can run high.
- Respect other people's privacy: don't post anyone's personal information, and
  redact secrets and private paths from logs you share.

## Unacceptable behavior

Harassment, insults, personal attacks, discriminatory or sexualized language or
imagery, publishing someone's private information without their permission, and
sustained disruption of discussions.

## Scope

This applies in the repository's issues, pull requests, discussions and other
project spaces, and when someone represents the project elsewhere.

## Reporting and enforcement

Report problems privately to the maintainer, Ivan Popov
([@aimagician](https://github.com/aimagician)), through
<https://ivanlabs.com/contact/>, or use GitHub's **Report content** option on
any comment. Reports are handled confidentially.

The maintainer may edit or remove content, and may warn, temporarily block or
permanently ban anyone whose behavior violates this code of conduct.

This code of conduct is inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/).
